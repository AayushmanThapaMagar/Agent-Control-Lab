# Scripted scenarios

Each `demo_fNN.py` sets up a fixture and checks the observable outcome.
Start with `demo_f06.py` to see an approved cleanup and a denied deletion.

From the repository root, run `python3 harness/scenarios/demo_f06.py` for
one scenario or `python3 harness/regress_scripted.py` for the full suite.

See the [failure-mode catalog](../../docs/failure_modes.md) for coverage.
