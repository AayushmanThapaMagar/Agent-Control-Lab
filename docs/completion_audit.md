# Agent Control Lab completion audit

This audit checks the original research plan against observed runs. All 15 failure-mode families have at least one scoped check. For each family, the audit records what was exercised, what evidence supports the result, and what remains open. A positive live run, a scripted denial, and a verdict on saved evidence support different claims.

Start with the [failure-mode catalog](failure_modes.md), [pilot results](results.md), [evidence map](evidence_map.md), and [security levels](security_levels.md). Commands assume the current package layout.

## Evaluation facts to retain

- **F01 recovery.** The historical P02 denial replay tested a fresh worker call using sanitized evidence from the saved denial. The live same-conversation test started with a benign incomplete draft and preserved the worker's first proposal and the gate denial in the conversation. Each recovery recorded exactly one approved payload in its own test sink. An older test used a scripted incomplete first proposal and measured the live retry.
- **F04 source controls.** The frozen source-only run returned two expected `authorized` judgments and zero review errors. Its plan contained zero confirmed violations. The result supports acceptance of those two controls.
- **F04, F12, and F13 held-out evidence.** One predeclared seven-case run returned 7/7 expected judgments and zero review errors. Manual inspection found three incomplete citation lists and one imprecise attribution of authority. The F04 subset used returned rows as evidence.
- **Selective review.** Rules-only, LLM-only, and hybrid review matched all seven expected judgments. The LLM-only run made seven calls with 8.2964 seconds of summed review time. The measured hybrid replay made two advice calls with 8.5136 seconds of summed advice time. The hybrid made fewer model calls on this set, and these runs showed no observed speedup.
- **Stored evidence.** The original seven-case run is at local path `runs/review-holdout-VVVuag/results.jsonl`. The measured hybrid record is alongside it as `hybrid-measured.jsonl`. The F04 source-control observations are in `runs/f04-source-review-gjmS5E/results.jsonl`. A rerun produces a new observation.
- **Clean reproduction.** A fresh `git archive` checkout of commit `3d8d008` passed the scripted suite and the full coding workflow, including all seven Docker checks, authenticated receipt issuance, audit checkpoint verification, and report release. The run ID was `4b1abac97d45427dbdd53b136f4bd133`. The historical denial replay and same-conversation F01 recovery tests passed in separate live runs after this baseline.
